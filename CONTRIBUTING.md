# Contributing to Confidant

Thanks for your interest in contributing to Confidant.

## Ways to Contribute

- report bugs
- suggest features
- improve docs
- submit pull requests
- review code
- help test deployments
- help support the developer by monetary means {by subscribing to the hosted,paid version}

## Code of Conduct

Be respectful, constructive, and professional in all interactions.
